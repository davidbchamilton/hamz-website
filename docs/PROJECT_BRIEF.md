# Project Brief

## Project Purpose

Official website for `[PRODUCER NAME]`, a Caribbean music producer.

Immediate objective:

Launch a polished promotional website in time for the Caribbean Music Awards.

Long-term objective:

Create a permanent professional online home for the producer, his production services, beat catalogue links, placements, press material, and direct industry relationships.

## Audiences

Primary:

- recording artists
- managers
- record labels
- music executives
- A&R representatives
- Caribbean music professionals
- potential production clients

Secondary:

- music fans
- journalists
- media
- sync/licensing clients

## Primary Website Goals

Visitors should be able to:

- understand who the producer is
- hear selected beats
- reach BeatStars
- discover production services
- view placements and credits
- view awards/nominations
- contact the producer
- access social media
- access press material
- request production work

Invited artists should additionally be able to:

- access `/cma`
- verify an invitation
- preview exclusive beat packs
- download private beat packs
- review usage/licensing terms

## Public Site

Expected main navigation:

- Home
- Beats
- Services
- About
- Contact

Additional public routes:

- Placements
- Press

The CMA beat-pack portal should not appear in the main navigation.
